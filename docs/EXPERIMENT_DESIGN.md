# 实验设计：三元量化 27B 在 8GB 显存上的能力解离现象

> 状态：**已执行**（2026-10-05）· 结果见 [FINDINGS.md](FINDINGS.md)（[English](FINDINGS.en.md)）
>
> 本文档是**设计稿**，记录实验矩阵、竞争解释排除方案与判读规则；
> 结论与实测数据在 [FINDINGS.md](FINDINGS.md)。
>
> 目标：回答一个学术共识假设未覆盖的问题——极低比特量化对模型能力的损失
> 是否是均匀的。

> **实测结论**：不是均匀的。语义类视觉能力 4/4 通过，
> 无位置提示的坐标定位命中 2/36（6%），格式损失 0/36。

---

## 0. 为什么要做这个实验

### 0.1 现有文献的共识

所有量化研究的默认前提是「**量化损失是均匀且小的**」：

| 来源 | 声称 |
|---|---|
| Stanford AI Lab (2024) | 4/8-bit 量化导致 perplexity 上升 **5–12%** |
| 通用量化指南 | "3–5% benchmark 准确率损失" |
| insiderllm 实测（Llama 3.1 8B） | Q8_0 → MMLU 63.4%，Q4_K_M → 62.4%（**丢 1 分**） |
| 论坛共识 | "Q2 是垃圾，Q4 是甜点" |

**共识的隐含推论**：量化主要损伤「通用能力」，各能力维度大致同步下降，
所以用一个平均分（MMLU / perplexity）就能概括。

### 0.2 本项目的异常观察

在我们的目标工作负载上，损失**不是均匀的**：

| 能力维度 | 观察 | 相对表现 |
|---|---|---|
| 中文口语意图分类 | 91% / 134 条，危险漏判 0 | **几乎无损** |
| 图像内容理解 | 能准确读出菜单项、报错信息 | **无损** |
| GUI 空间定位（grounding） | 纯色点偏 224px，远端点偏 1426px | **归零** |
| 长会话稳定性 | prompt 6723 token 即出现退化 | **显著受损** |
| 组合键/坐标推理类任务 | 未系统测 | **未知** |

如果这个解离在受控实验中得到确认，它意味着：

1. **单一平均分不足以描述极低比特模型的实用性**——需要按能力维度分别报告。
2. **「模型变笨了」这句话是错的**：不是整体变笨，是**特定能力被选择性抹掉**，
   而这些能力恰好是 GUI agent 所依赖的。
3. 现有量化研究的评测集（MMLU 等）**不覆盖空间推理维度**，因此看不到这个现象。

**这不是"发现模型有 bug"，而是"发现评测指标与实际可用性之间存在缺口"。**

### 0.3 为什么必须做对照

我们只测了一个模型（PTQ1 27B）+ 一个对照组（Qwen3.5-0.8B，不是量化对照）。

**没有同精度 FP 基线，就没有"量化造成了多少损失"的说法。**
这是本设计最需要防守的质疑，必须正面处理（见 §5）。

## 1. 三个必须排除的竞争解释

在得出「解离是量化造成的」之前，必须排除以下三种可能。
**任何一条不排除，结论都不成立。**

| # | 竞争解释 | 如何排除 | 所需实验 |
|---|---|---|---|
| **C1** | 不是量化造成的，是**模型本身**就这样（训练/架构缺陷） | 同模型换更高精度权重对比；若找不到同源 FP 权重，用**同系列更大模型**做趋势检验 | §3 实验组 D |
| **C2** | 不是量化造成的，是**分辨率/输入处理**出了问题 | 固定量化，改变输入分辨率与预处理，观察 grounding 是否改善 | §3 实验组 C |
| **C3** | 不是能力缺失，是**输出格式不合规**——模型答对了但格式没按要求 | 允许宽松格式重测，统计"语义正确但格式错误"的比例 | §3 全部（格式审计环节） |

**C3 特别重要**：我们此前刻意采用「只接受纯坐标格式，否则判失败」的严格解析。
如果模型其实答对了位置但附带了解释文字，严格解析会把它记成失败，
从而**人为制造"能力缺失"的假象**。这个陷阱必须显式测量。

## 3. 实验组设计

### 3.1 能力探针（Probe）——复用于所有实验组

**四个探针，覆盖四个能力维度：**

| 探针 | 测什么 | 标准答案构造 | 指标 |
|---|---|---|---|
| **P1 意图分流** | 中文口语语义理解 | 134 条已建基准 | 准确率 / **危险漏判数** |
| **P2 图像内容理解** | 看懂图里有什么 | 合成图 + 人工标注 | 描述准确度（人工/LLM 评判） |
| **P3 空间定位** | 能否给出坐标 | 合成纯色点，坐标无争议 | 欧氏距离（px） |
| **P4 长会话稳定性** | 上下文增长下的退化 | 合成轮次脚本 | 首次退化轮次 / 是否进入五态 |

**P1 的「危险漏判」必须单列**，不能被准确率掩盖：
一个把"删库"判成闲聊的模型，准确率 99% 也是危险的。

**P2 的判定必须人工确认**，不能只靠 LLM 打分——我们正是在用 LLM 评估 LLM 能力时翻过车。

### 3.2 P3 空间定位的实验矩阵（核心）

**为什么必须是纯色点：** 任何真实 UI 元素都可能被误识别为"别的东西"。
纯色点排除了一切歧义，模型答错只能是能力问题。

**设计：**

| 分组 | 图片尺寸 | 目标 | 标准答案 | 目的 |
|---|---|---|---|---|
| G1 | 1024×683 | 纯色圆点 ×2 | 精确坐标 | 基线 |
| G2 | 1536×1024 | 纯色圆点 ×2 | 精确坐标 | 分辨率敏感性 |
| G3 | 2560×1600 | 纯色圆点 ×2 | 精确坐标 | 超出位置编码范围 |
| G4 | 1024×683 | 10×10 网格标号 | 指定格中心 | 排除"看不懂" |
| G5 | 1024×683 | 纯色圆点 | 精确坐标 | **KV 在 RAM vs 显存** |

**每个目标点必须在图像的四个象限各出现一次**（左上/右上/左下/右下），
避免"往中心猜"这个策略偶然命中。这是此前实验的一个教训——
红点在左上时"猜中心"恰好更接近，看起来在改善，实际是策略巧合。

**G5 是核心对照**：同一张图、同一模型、同一采样，只切 `--kvmem-cpu-gb`。
若 grounding 表现随 KV 位置变化，**说明这个"能力"其实从未存在于有效上下文中，
只是被长上下文噪声淹没了**——这是本项目最有可能产出的非平凡结论。

### 3.3 C3 格式审计（必须做，成本极低）

对每次 P3 询问，**记录模型原始输出的完整文本**，然后用三种解析器各判一次：

```
宽松解析:  允许任意格式，用 re.search 抠出第一对数字
严格解析:  只接受 "123,456" 纯坐标（当前实现）
语义判定:  人工/LLM 判断"这个回答指的是不是正确的点"
```

**三种判定结果不一致的样本，全部人工复核。**

关键指标：
```
格式损失率 = 严格解析判失败 但 语义判定正确的样本数 / 总样本数
```

**若这个值显著 > 0，我们此前的"grounding 能力缺失"结论就需要修正**
——那不是能力缺失，是输出格式不合规。这是一个**可能推翻自己已有结论**的实验，
所以必须做。

### 3.4 P4 长会话退化的边界测量

用脚本生成长会话，**只改变 prompt 总 token 数**，测退化出现的临界点：

| 轮次 | 目标 prompt token |
|---|---|
| R1 | 85（基线） |
| R2 | 500 |
| R3 | 2000 |
| R4 | 4000 |
| R5 | 6723（已知的退化点） |
| R6 | 12000 |

每组记录：首 token 延迟、总耗时、五态命中情况、是否空转。

**每个 token 档位 × KV 位置（RAM/显存）= 一组，共 12 组。**

## 5. 诚实的边界声明（这一节必须写进最终报告）

### 5.1 最重要的一条：没有 FP 基线

**本实验无法证明"解离是量化造成的"。** 因为：

- 我们只有 PTQ1 权重，**没有同源 FP 或 Q8 权重**做对照
- 不同量化等级之间的比较 = 换了模型 = 换了训练状态
- 所以只能说「**在 PTQ1 这个量化等级上，观察到能力解离现象**」，
  不能说「**量化导致了能力解离**」

**要证明后者，需要：**
1. 找到同系列更高精度权重（若 Bonsai 有 Q4/Q8 版本）→ 最好
2. 或用其他模型跑同一套探针，看解离是否**只出现在极低比特模型上**
   → 若 7B/8B Q4 模型的 grounding 正常，则**间接支持**量化假设

**第 2 条即使没有第 1 条也能做，而且成本不高。** 建议补。

### 5.2 样本量限制

- P1 有 134 条（够用）
- P3 每个点 4 个象限 × 2 模型 × 5 分组 = 40 次推理（**偏少**）
- P4 12 组（够看趋势，**不够算统计显著性**）

**所有结论必须标注样本量。** 不要把小样本的差异说成规律。

### 5.3 不能声称的内容

- ❌ "PTQ1 模型无法做 GUI agent" → 只能说"PTQ1 + 我们的探针下未通过"
- ❌ "三元量化会摧毁空间能力" → 需要跨模型验证
- ❌ "N 位量化下能力解离普遍存在" → 只测了一个量级

## 7. 预期结果与判读规则

**必须预先声明判读规则**，避免事后找解释：

| 若观察到 | 则可声称 |
|---|---|
| 严格解析失败但语义判定正确 > 30% | 「grounding 能力此前被误判，实为格式问题」**修正已有结论** |
| KV 位置变化导致 grounding 显著变化 | 「长上下文噪声掩盖了定位能力」——**非平凡结论** |
| 退化临界点在 RAM/显存下不同 | 「KV 落盘降低了有效上下文」——直接命中研究空白 |
| 全部实验无显著差异 | **如实报告阴性结果**，说明该现象在此探针下不成立 |

**最后一行同样是有价值的产出。** 阴性结果 + 完整数据 = 排除了一条路，
也是贡献。我们此前两次最有价值的信息都来自"实测推翻了推断"。
